# Feature Specification: 教室大螢幕投影專用視圖

**Feature Branch**: `012-projector-view`（本專案未建立功能分支，於目前分支開發；規格目錄為 `specs/012-projector-view`）

**Created**: 2026-11-12

**Status**: Draft

**Input**: User description: "Step 12: 教室大螢幕投影專用視圖。目標：課堂競賽感與大螢幕展示。驗證效果：老師另開一個投影專用網址，介面放大且隱藏控制按鈕，呈現搶答倒數動畫、即時各題得主看板與組別得分排行榜。"

> **用語說明**：**投影視圖**＝給教室大螢幕／投影機展示的唯讀畫面，有自己專用的網址；**投影網址**＝老師從老師端取得、貼到投影電腦開啟的連結，只含唯讀的投影憑證；**得主看板**＝各題（題組整組一格）目前的獲勝組別與答案；**得分**＝一個組別累計取得的題數（題組內 N 題計 N 題，沿用 Step 7、Step 9、Step 11 的計法）；**排行榜**＝各組得分由高到低的排名；**結算**＝老師結束搶答、公布結果的時間點（Step 6）；**倒數動畫**＝老師開始搶答時在投影畫面播放的「3、2、1、開始！」視覺動畫。名次、有效第一名、讓位沿用 Step 5、9、11，本步驟不改變任何仲裁、審核、分配或回填的結果。

## Clarifications

### Session 2026-11-12

- Q: 搶答進行中，大螢幕要不要即時顯示各題「目前領先的組名」？ → A: 不顯示；搶答中只顯示匿名進度（「已有組別送出」與總進度），得主組名與答案結算後才顯示，完全符合憲章原則 III，不設開關
- Q: 「搶答倒數動畫」要怎麼和學生端開放輸入的時間配合？ → A: 純視覺、不延後；老師按開始時學生端立即開放，投影同時播放「3、2、1、開始！」，不新增倒數階段、不動階段與仲裁規則
- Q: 組別得分排行榜的「得分」要怎麼算？ → A: 已結算各輪取得題數的累計（題組 N 題計 N）；進行中的新一輪結算前不計入，無加權

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 老師取得專用投影網址，在大螢幕開啟唯讀、放大、無控制按鈕的畫面 (Priority: P1)

老師在老師端按一個按鈕取得「投影網址」，把它開在連接投影機的電腦或瀏覽器分頁上。這個畫面字級放大、對比高，**沒有任何控制按鈕或輸入欄位**：無法開始／結束搶答、審核、回填、匯出或結束房間。它隨時顯示房間目前的階段：等待搶答時顯示房間代碼與已加入的組別，讓學生看著大螢幕加入；搶答中與結算後顯示各自的內容（見 US2、US3）。

**Why this priority**: 這是驗證效果的第一句話（專用網址、放大、隱藏控制按鈕），也是其他投影內容的載體；沒有它就沒有大螢幕展示。

**Independent Test**: 老師建立房間後取得投影網址並在另一個視窗開啟；畫面顯示房間代碼與已加入組別，字級明顯放大，頁面上找不到任何會改變房間狀態的按鈕；用這個網址嘗試任何老師操作都被拒絕。

**Acceptance Scenarios**:

1. **Given** 老師已建立房間, **When** 在老師端按「開啟投影視圖」, **Then** 取得一個專用的投影網址（可複製、可在新分頁開啟），網址中不含老師憑證。
2. **Given** 投影視圖已開啟且階段為等待搶答, **When** 有組別加入, **Then** 畫面即時顯示房間代碼與該組名（大字），不需任何操作。
3. **Given** 投影視圖已開啟, **When** 檢視整個畫面, **Then** 沒有任何開始／結束搶答、審核、回填、匯出、結束房間或輸入欄位。
4. **Given** 持有投影網址的人, **When** 嘗試用它執行任何老師操作（開始／結束、審核、回填、匯出、結束房間、讀取答案內容之外的老師資料）, **Then** 一律被拒絕。
5. **Given** 老師更換裝置並以恢復碼回復老師端, **When** 再次取得投影網址, **Then** 取得的是同一個房間的有效投影網址（先前已開啟的投影視圖仍可繼續使用）。
6. **Given** 兩個以上的投影視圖同時開啟, **When** 房間狀態變化, **Then** 它們同步更新、互不影響，也**不會**被計為組別（不出現在在線組別清單、不占用組名）。
7. **Given** 一個格式錯誤、已不存在或已被作廢的投影網址, **When** 開啟, **Then** 顯示明確的「無法顯示」提示，且不透露該房間是否存在。

### User Story 2 - 搶答倒數動畫與搶答中的進度看板（不洩漏答案） (Priority: P1)

老師按「開始搶答」時，投影畫面播放「3、2、1、開始！」的大型倒數動畫，帶出競賽的氣氛。動畫之後，畫面顯示各題的進度：每題（題組整組一格）只顯示「尚無組別送出」或「已有組別送出」與總進度；**不顯示任何組名、答案、名次或讓位／保留資訊**（憲章原則 III）。

**Why this priority**: 倒數動畫是驗證效果指定的呈現，而搶答中的看板必須先確定不會洩漏，大螢幕全班可見，風險最高。

**Independent Test**: 老師開始搶答，投影視圖播放倒數動畫後切到進度看板；學生送出答案時，對應題目即時從「尚無組別送出」變成「已有組別送出」，但整個畫面與所有傳到投影視圖的資料都找不到任何組名或答案。

**Acceptance Scenarios**:

1. **Given** 投影視圖已開啟且階段為等待搶答, **When** 老師按「開始搶答」, **Then** 投影畫面播放約 3 秒的倒數動畫（3、2、1、開始！），之後顯示搶答中的進度看板。
2. **Given** 倒數動畫正在播放, **When** 學生端已開放輸入並有組別送出, **Then** 動畫不影響學生端的開放時間、送出、名次或任何仲裁結果（動畫純為視覺效果）。
3. **Given** 搶答中, **When** 某組送出某題, **Then** 投影視圖該題即時變為「已有組別送出」，並更新整體進度（例如「已有答案的題目 3／6」）。
4. **Given** 搶答中, **When** 檢視投影視圖與其收到的全部資料, **Then** 不含任何組名、答案、名次、送出時間、讓位或保留資訊，也不顯示哪一組送出。
5. **Given** 倒數動畫播放後、或投影視圖在搶答中途才開啟／重新整理, **When** 載入, **Then** 直接顯示搶答中的進度看板，**不**重播倒數動畫。
6. **Given** 老師在新的一輪再次按「開始搶答」, **When** 開始, **Then** 投影視圖再次播放倒數動畫並清空上一輪的進度。

### User Story 3 - 結算後的各題得主看板與組別得分排行榜 (Priority: P1)

老師結束搶答、公布結果後，投影視圖顯示兩個區塊：**各題得主看板**——每題（題組整組一格）的獲勝組別與其答案；**組別得分排行榜**——各組累計取得的題數由高到低排名（同分並列）。老師之後審核（駁回／恢復）或遇到上限讓位時，看板與排行榜即時依重新分配的結果更新，與學生端結果頁一致。

**Why this priority**: 這是驗證效果的核心展示——即時各題得主與得分排行榜，製造課堂競賽感。

**Independent Test**: 兩組各搶得數題後老師結束搶答；投影視圖顯示每題得主組名與答案、無人搶答的題目標示為無人搶答，排行榜依得分排序且同分並列；老師駁回某筆答案後，看板與排行榜在數秒內自動更新，並與老師端、學生端的結果逐題一致。

**Acceptance Scenarios**:

1. **Given** 搶答已結束, **When** 檢視投影視圖, **Then** 顯示每題的得主組名與答案；題組顯示為一格並列各小題答案；沒有人搶答的題目標示「無人搶答」；全被駁回者標示「無有效答案」。
2. **Given** 搶答已結束, **When** 檢視排行榜, **Then** 各組依得分由高到低列出（題組取得計 N 題），同分者名次並列，得分為 0 的組別也列出。
3. **Given** 老師駁回或恢復某筆答案, **When** 重新結算, **Then** 看板與排行榜即時更新為重新分配後的結果，並與老師端、學生端的結果逐題一致。
4. **Given** 房間設有上限（Step 11）, **When** 某組因達上限讓位, **Then** 看板顯示讓位後的得主，排行榜得分採讓位後的結果。
5. **Given** 已進行多輪搶答, **When** 檢視排行榜, **Then** 得分為所有**已結算**輪次取得題數的累計；進行中的新一輪在結算前不計入，也不在畫面上顯示其內容。
6. **Given** 投影視圖顯示結算後的內容, **When** 老師開始下一輪, **Then** 切換回倒數動畫與搶答中進度看板，排行榜維持顯示累計得分（不含進行中的新一輪）。
7. **Given** 結算後的看板, **When** 檢視畫面與收到的資料, **Then** 不含被駁回者、審核理由、原始名次、送出時間或讓位細節（只有得主組名與答案、得分）。

### User Story 4 - 斷線重連、房間結束與沒有題目的房間 (Priority: P2)

投影電腦的網路可能中斷或被重新整理。投影視圖在連線狀態改變時要清楚呈現，並在恢復後由後端還原到目前的正確內容。房間被結束時顯示「房間已結束」並保留最後成績；沒有綁定試算表（沒有題目）的房間也能開投影視圖，只顯示房間代碼與組別。

**Why this priority**: 大螢幕不能卡在過期畫面；但不影響主要展示流程，屬於穩健性。

**Independent Test**: 在搶答中斷開投影電腦網路再恢復，畫面顯示斷線提示後自動還原為目前的階段與內容；老師結束房間後投影視圖顯示「房間已結束」與最後排行榜；無題目房間的投影視圖只顯示代碼與組別。

**Acceptance Scenarios**:

1. **Given** 投影視圖開啟中, **When** 連線中斷, **Then** 畫面明顯顯示「連線中斷，重新連線中」，恢復後自動還原為後端目前的正確內容，不顯示過期的看板。
2. **Given** 投影視圖重新整理, **When** 重新載入, **Then** 立即由後端還原目前階段與內容（不依賴本機暫存）。
3. **Given** 房間已被老師結束或閒置逾時結束, **When** 檢視投影視圖, **Then** 顯示「房間已結束」，並保留最後的得主看板與排行榜。
4. **Given** 沒有綁定試算表的房間, **When** 開啟投影視圖, **Then** 顯示房間代碼與已加入組別，不顯示題目看板，排行榜得分皆為 0。

### Edge Cases

- 投影網址被洩漏給學生：學生只能看到本來就會公開的內容（搶答中為匿名進度，結算後為得主與得分），看不到任何老師才能看的資料，也無法執行任何操作。
- 老師結束搶答的同時有組別剛送出：以後端結算時的紀錄為準，投影視圖顯示結算結果，不顯示處理中的不一致畫面。
- 老師審核造成得主改變：看板上被連動改變的題目只顯示最新結果（不顯示審核過程）。
- 組別名稱很長或組別很多（例如 20 組）：排行榜仍須在一個畫面內可讀（長名稱截斷顯示並保留完整名稱的檢視方式不在本步驟範圍，僅確保不破版）。
- 題目很多（例如 30 題）：看板分欄／縮小排版以在一個畫面內呈現，不需要操作捲動。
- 同一輪內得分相同的組別：名次並列，同分組別之間依組名排序以保持畫面穩定。
- 投影視圖連線數量：老師端的「在線組別」不受投影視圖影響。
- 房間已不存在（服務重啟、24 小時過期）：顯示「無法顯示」提示，不洩漏資訊。
- 瀏覽器不支援動畫或使用者偏好減少動態效果：倒數仍以靜態數字逐秒顯示，內容不遺失。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系統 MUST 讓老師在老師端取得本房間專用的**投影網址**；網址 MUST 只含唯讀的投影憑證，MUST NOT 含老師憑證或恢復碼；投影憑證在房間存續期間固定，老師以恢復碼換裝置後仍可取得同一個。
- **FR-002**: 投影視圖 MUST 為唯讀：畫面 MUST NOT 提供任何控制按鈕或輸入欄位（開始／結束搶答、審核、回填、匯出、結束房間等）；持有投影憑證 MUST NOT 能對房間執行任何寫入或老師才有的操作。
- **FR-003**: 投影視圖 MUST 採放大版面（大字、高對比、適合遠距離閱讀），並隨階段顯示：等待搶答（房間代碼、已加入組別）、搶答中（進度看板）、已結束（得主看板＋排行榜）。
- **FR-004**: 老師開始搶答時，投影視圖 MUST 播放約 3 秒的倒數動畫（3、2、1、開始！）；動畫 MUST 純為視覺效果：MUST NOT 延後學生端開放、MUST NOT 影響任何送出、名次或仲裁；中途才載入或重新整理的投影視圖 MUST NOT 補播動畫。
- **FR-005**: 搶答中，投影視圖 MUST 只顯示每題（題組整組一格）的匿名狀態（「尚無組別送出」／「已有組別送出」）與整體進度；MUST NOT 顯示或傳送任何組名、答案、名次、送出時間、讓位／保留資訊（憲章原則 III）。此限制 MUST 由後端控制傳給投影視圖的資料，而非僅由畫面隱藏。
- **FR-006**: 結算後（階段為已結束），投影視圖 MUST 顯示各題得主看板：每題得主組名與答案（題組一格並列各小題）；無人搶答、全被駁回分別標示；內容 MUST 與學生端結果公布完全一致（同一份有效結果，含審核與 Step 11 公平規則）。
- **FR-007**: 結算後，投影視圖 MUST 顯示組別得分排行榜：得分＝各組在所有**已結算**輪次取得的題數累計（題組 N 題計 N）；依得分由高到低、同分名次並列（同分者依組名排序）、得分為 0 的組別也列出；進行中輪次結算前 MUST NOT 計入。
- **FR-008**: 老師審核（駁回／恢復）或其他使結果改變的事件發生後，投影視圖的看板與排行榜 MUST 即時更新為重新分配後的結果，且 MUST NOT 顯示被駁回者、審核理由、原始名次或送出時間。
- **FR-009**: 投影視圖 MUST 透過即時同步取得更新，斷線時 MUST 明顯顯示連線狀態，重連或重新整理後 MUST 由後端還原目前正確內容，MUST NOT 依賴本機暫存作為事實來源。
- **FR-010**: 投影視圖 MUST NOT 被計為組別（不占組名、不出現在老師端組別清單、不影響在線／離線狀態）；同一房間 MUST 可同時開啟多個投影視圖。
- **FR-011**: 無效、格式錯誤或不存在的投影網址 MUST 顯示明確的無法顯示提示，且 MUST NOT 透露房間是否存在；房間結束後 MUST 顯示「房間已結束」並保留最後的看板與排行榜。
- **FR-012**: 沒有題目的房間 MUST 仍可開啟投影視圖，顯示房間代碼與組別；不顯示題目看板。
- **FR-013**: 本功能 MUST NOT 改動任何既有紀錄、名次、審核、公平分配、回填或匯出的結果；投影視圖僅讀取既有的有效結果。
- **FR-014**: 使用者偏好減少動態效果時，倒數 MUST 改為無動畫的逐秒數字顯示，內容完整不遺失。

### Key Entities

- **投影憑證**：房間專屬、唯讀、房間建立時產生並固定；只能用來開啟投影視圖，無法執行任何寫入或老師操作；與老師憑證、恢復碼不同。
- **投影視圖內容**：隨階段推導的唯讀畫面資料——等待搶答（房間代碼、組別名單）、搶答中（各題匿名狀態與總進度）、已結束（各題得主組名與答案、各組得分排行）；全部由後端推導，不另存。
- **組別得分**：由各已結算輪次的有效結果推導，＝該組取得題數累計；不另存、可重現。
- **倒數動畫事件**：開始搶答時由階段變更觸發的純視覺提示，不含任何仲裁資訊，晚到的連線不補播。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 老師從按下「開啟投影視圖」到大螢幕顯示房間代碼與組別，在 10 秒內完成，不需任何額外設定。
- **SC-002**: 搶答結算、審核或恢復後，投影視圖的看板與排行榜在 3 秒內更新為正確結果；投影視圖與老師端、學生端的各題得主 100% 一致。
- **SC-003**: 搶答中，傳到投影視圖的所有資料與畫面中，組名、答案、名次、送出時間、讓位／保留資訊的外洩數為 0。
- **SC-004**: 投影視圖上可改變房間狀態的控制項為 0 個；以投影憑證嘗試的老師操作成功率為 0%。
- **SC-005**: 在 1920×1080 的投影解析度下，組名、得分與題號文字在一般教室後排（約 8 公尺）可清楚閱讀；30 題、20 組的房間仍能在一個畫面內完整呈現，無需捲動。
- **SC-006**: 倒數動畫完整播放（約 3 秒），且學生端開放輸入的時間與先前步驟相比沒有任何延後；晚載入的投影視圖補播動畫的次數為 0。
- **SC-007**: 投影電腦斷線後恢復，畫面在 5 秒內還原為後端目前的正確內容；斷線期間畫面有明確的連線中斷提示。

## Assumptions

- **倒數動畫的語意（已於 Clarifications 確認）**：老師開始搶答的同一時刻學生端立即開放（沿用 Step 2）；投影畫面同時播放「3、2、1、開始！」純視覺動畫，不延後開放、不另設倒數階段，以免更動階段與仲裁規則。若老師希望「先倒數、倒數結束才開放輸入」，需另行調整階段規則，不在本步驟內。
- **搶答中的「即時」範圍（已確認）**：憲章原則 III 禁止在結算前向其他組別洩漏送出狀態細節，大螢幕等同全班可見，因此搶答中只顯示匿名的「已有組別送出」與總進度；各題得主組名與答案在**結算後**才顯示（結算後審核造成的變動則即時更新）。老師端的即時進度板（含領先組別）維持不變。
- **得分定義（已確認）**：得分＝已結算輪次取得題數累計（沿用 Step 11 的有效結果與題組 N 題計 N 的算法）；獲勝上限仍是每輪各自計算，排行榜的累計不會影響上限規則。尚未提供：加權計分、手動加減分、跨房間排行。
- **投影憑證**：房間建立時產生一個唯讀的投影憑證（與老師憑證分開），放在投影網址中；網址持有者可看到的內容等同「全班公開的內容」（搶答中匿名進度、結算後得主與得分）。憑證不提供作廢／重新產生，房間結束後即失效。
- **投影視圖不登入、不加入組別**：不需輸入組名或老師憑證，只用專用網址開啟；不計入在線組別。
- **畫面互動**：投影視圖為純展示頁，不提供全螢幕切換按鈕（可用瀏覽器全螢幕快捷鍵）；字級與版面針對寬螢幕（16:9）最佳化，其他比例以不破版為準。
- **範圍外**：音效、投票／觀眾互動、多房間輪播、投影畫面主題自訂、老師端遠端控制畫面切換、匯出排行榜圖片。
- **既有行為不變**：階段、送出、名次、審核、公平規則、回填與匯出完全沿用先前步驟；紀錄仍只存在記憶體（房間結束後保留 24 小時、服務重啟即消失）。
