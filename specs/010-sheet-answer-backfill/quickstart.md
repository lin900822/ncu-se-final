# Quickstart：答案自動寫入回原 Google Sheet 驗證

## 前置條件與啟動
同 [Step 3](../003-sheet-question-form/quickstart.md)～[Step 9](../009-answer-review-succession/quickstart.md)：`backend/.env` 設好機器人金鑰；前後端啟動方式相同。

> **新前置條件**：要實際回填，試算表必須共用給機器人帳號（金鑰內的 `client_email`）並設為**編輯者**。
> 只共用為檢視者時，讀取與搶答照常運作，但回填會得到「請將試算表共用給〈機器人 email〉並設為編輯者」。
> 建議先複製一份學習單範本來測試，避免弄壞正式教材（Google 試算表的「版本記錄」可還原誤寫）。

## 自動化測試
```bash
cd backend && uv run pytest
cd frontend && npx tsc -b      # 於 frontend/ 內 nvm use
```
預期通過（皆不連線 Google，使用記憶體中的 `fake_sheet`，另以 `MockTransport` 驗證實際送出的請求）：精準回填、不破壞其他格、純文字原樣寫入、
題組與合併儲存格、略過／清空／保留、預覽不寫入、全有或全無、結構驗證、權限與外部錯誤對應、時機與未授權、重複與併發、回填紀錄與還原。
既有 Step 1～9 測試仍全數通過（`SHEETS_SCOPE` 仍為唯讀）。

## 手動驗證情境（需要一份已共用為「編輯者」的真實試算表）

準備：老師貼單題範例連結建立房間（可先在預覽把 Q3、Q4 設為題組）；「第 1 組」「第 2 組」加入；老師開始搶答；
第 1 組先、第 2 組後送出 Q1（第 1 組填亂填答案），第 2 組另送 Q2 答案 `=1+1`；老師結束搶答。

| # | 步驟 | 預期（對應規格） |
|---|------|------------------|
| 1 | 搶答**進行中**檢視老師端「回填至 Google Sheet」 | 按鈕停用並說明搶答結束後才能回填（US3-5、FR-002） |
| 2 | 結束搶答後，先在試算表 Q2 的作答格手動打一個字，再按「回填至 Google Sheet」 | 顯示確認摘要：寫入 2 格、略過其餘題數、其中 1 格原有內容將被覆寫；此時試算表**尚未**被改動（US4-1、FR-011） |
| 3 | 按「取消」 | 試算表不變、沒有回填紀錄（US4-1） |
| 4 | 再按回填 → 「確認回填」 | 結果摘要顯示寫入 2 格與完成時間，並有「開啟試算表」連結（US1-5、SC-009） |
| 5 | 重新整理那份 Google Sheet | Q1 作答格＝第 1 組答案、Q2 作答格顯示文字 `=1+1`（不是 2）；題號欄、題目欄與其他內容不變；沒有答案的題的作答格維持原狀（US1-4、US2-1、US2-2） |
| 6 | 老師駁回 Q1 第 1 組的答案（Step 9），再按回填並確認 | Q1 作答格改為第 2 組的答案，沒有殘留舊答案（US1-2、US4-2、SC-006） |
| 7 | 老師把 Q1 所有送出都駁回，再回填 | 摘要顯示「清空 1 格」；確認後 Q1 作答格變回空白（US4-3） |
| 8 | 在 Q1 作答格手動打字後（老師改過），再回填 | 該格被「保留」不動，不會被清空（保留數 +1） |
| 9 | 結果不變時再回填一次 | 試算表不變、無錯誤，回填紀錄多一筆（US4-4） |
| 10 | 檢視老師端「回填紀錄」，並換瀏覽器以恢復碼回復 | 每次嘗試一筆（時間、輪次、寫入／略過／清空／保留、結果）；換裝置後仍在（US4-5） |
| 11 | 在試算表中插入一列（或改題號、改分頁名）後再回填 | 被拒絕並說明試算表已變動、請重新建立房間；試算表沒有被改動；紀錄多一筆失敗（US2-6、SC-004） |
| 12 | 把機器人改為「檢視者」後再回填 | 提示需要「編輯者」並顯示機器人 email；試算表不變；紀錄多一筆失敗（US3-1） |
| 13 | 連續快速點擊「確認回填」 | 只寫入一次、只有一筆紀錄（US4-6） |
| 14 | 以 `curl` 不帶憑證、錯誤憑證、憑證放網址呼叫兩個端點 | 皆回 401，試算表不變（US3-7、SC-007） |
| 15 | 檢視學生端畫面與 WebSocket 訊息 | 找不到任何回填入口、回填紀錄或內容（FR-022） |
| 16 | 以未綁定試算表的房間（直接建立房間）檢視面板 | 回填按鈕停用並說明未綁定試算表（US3-6） |

契約見 [rest-api.md](./contracts/rest-api.md)、[websocket.md](./contracts/websocket.md)、[google-sheets-write.md](./contracts/google-sheets-write.md)；資料見 [data-model.md](./data-model.md)。

## 實作後的圖表一致性檢查（Constitution VI）
比對 `diagrams/*.puml` 與程式（`BackfillRecord`／`BackfillPlan` 欄位與推導規則、回填服務的驗證順序與互斥、預覽唯讀與確認重算、
批次全有或全無寫入、`backfill_updated` 受眾）；不一致時修正程式或更新圖表，並重新產圖：
```bash
java -jar plantuml.jar -charset UTF-8 -tpng diagrams/*.puml
```
（本機若無 Graphviz，加 `-Playout=smetana`。）
